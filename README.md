# Élan Motors

> French Electric Urban Hatchbacks — Style Meets Sustainability

**Élan Motors** is a premium French electric vehicle brand designing compact urban hatchbacks that blend Parisian elegance with cutting-edge EV technology. Built for the modern European city dweller who refuses to compromise on design or sustainability.

## ⚡ Features

- **All-Electric Powertrain** — Zero-emission driving with ultra-fast charging capability
- **Compact Urban Design** — Purpose-built for narrow European streets with a tight turning radius
- **Premium Interior** — Sustainably sourced materials, minimalist French design language
- **Smart Connectivity** — Integrated navigation, remote climate control, and OTA software updates
- **Safety Suite** — Advanced driver assistance with pedestrian and cyclist detection
- **Battery-as-Service** — Optional battery subscription model to lower upfront cost

## 🛠 Tech Stack

- **Web:** HTML5, CSS3, JavaScript (vanilla)
- **Design:** Custom responsive layout, CSS Grid, Flexbox
- **Assets:** Optimized imagery, custom iconography
